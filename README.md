## 线路分四级，延迟差一倍

从美国到中国大陆走哪条路由，直接决定你 SSH 会不会卡。普通国际线路（BGP/T1）高峰期 200-300ms 是常态；CN2 GT 走电信精品网，但不是最高一档；CN2 GIA 三网回程全走精品网，延迟稳定在 150-180ms；CMIN2 和 AS9929 在联通、移动方向表现更好，电信方向略逊，价格比 CN2 GIA 低一截。

同一家内部的价格差最能说明问题。DMIT 的 T1 系列 1 核 1GB/20GB 是 $36.9/年，Pro（CN2 GIA）和 EB（CMIN2）的 1 核 2GB/20GB 都是 $88.88/年。内存多 1GB，年付贵 52 美元，多出来的钱买的是回程路由。

选哪一档看你的宽带类型。电信用户要极致稳定，CN2 GIA 的溢价花得值；联通、移动用户拿 CMIN2 或 AS9929 的机器，体感和 CN2 GIA 差距很小，账单能省一截。商家把这两条线拆成两个系列分别定价，原因就在这里。

## 第二年的账：首年折扣价不能当长期成本

促销码大多只对新购首年生效。有商家把条件写在明面上：首年 8 折，新购专享，续费不能用，同时承诺续费同价。拿 188 元/年的 2 核 4GB 那档算，首年 150.4 元，第二年 188 元，两年合计 338.4 元，平均每年 169.2 元。做预算按 169 元/年比按 150 元/年靠谱。

年付和月付的差距更大。同一家的 T1 系列，1 核 1GB/20GB、1000GB 月流量的年付款是 $36.9；1 核 1GB/20GB、2000GB 月流量的月付款是 $6.90/月，一年 $82.8。年付大约是月付的 45%，流量还少一半。用月付验证线路，确认没问题再转年付，这笔钱不算浪费。

还有一件常被忽略的事：美元计价的商家，第二年续费要按当时汇率折算，人民币报价对国内用户更直观，预算做起来也简单。

## 只写在条款里的五条限制

1. 流量用完限速，不停机。野草云的美国套餐流量耗尽后限到 1Mbps，次月 1 号重置；DMIT 是超出后限速继续跑，阈值按套餐不同。
2. 25 端口默认阻断。要搭邮件服务器得单独申请，野草云的做法是交 150 元保证金，取消服务器时全额退回，理由是防垃圾邮件投诉。
3. IP 被墙后的免费更换有周期。DMIT 的 Premium 和 Eyeball 系列每 15 天可免费换一次，其他情况 $5 一次；野草云是开机 24 小时内发现 IP 有问题免费更换。
4. 不超卖的商家会缺货。DMIT 明确写了不超卖，代价是热门套餐经常售罄，看到合适的别拖太久。
5. 登录方式可能是密钥。DMIT 默认 SSH 密钥登录，不支持密码，新手要预留时间按教程配置。

这几条都不在套餐表里，却能在用到第二周时改变你的判断。

## 原生 IP 和住宅 IP 是两回事

很多页面把两个词混着用。机房原生 IP 指 IP 段由 ARIN 或 RIPE 分配给机房，地理位置登记在美国，适合建站、跑 API、做常规服务。住宅 IP 走的是当地宽带运营商的线路，卖点是账号环境干净。

丽萨主机的美国纽约套餐是双 ISP 家宽住宅 IP，主打 TikTok 运营和美区流媒体解锁，页面同时写明“非大陆优化网络，建议通过香港或日本线路中转”，并建议开 BBR。要国内用户打开快，这台机器不合适；要做美区账号环境，它比机房 IP 省事。

拿住宅 IP 的机器当建站主力，国内访问会慢到影响使用。按用途选 IP 类型，比按价格选更少踩坑。
